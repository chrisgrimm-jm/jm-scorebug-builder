# JM Scorebug Builder

Designer tool for JM Graphics: turn a zip of full-frame PNG scorebug pieces into a style file the graphics op
imports. Runs entirely in your browser; nothing is uploaded anywhere.

Open: https://chrisgrimm-jm.github.io/jm-scorebug-builder/

Generated by `publish_designer.py` in the (private) jm-graphics repo; edit there, not here.
