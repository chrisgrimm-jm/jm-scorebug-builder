Scorebug setup

Build a scorebug from PNG pieces

  1. Export every piece as a full-frame PNG (1920×1080, transparent, in position), plus one full bug for reference PNG. Put team/player options in folders (e.g. Left teams). Zip it.
  2. Pick the sport and name the style above, then Open PNG zip. Auto build sets up what it can from the reference.
  3. Check each piece, rename the {text1}… fields (e.g. {awayScore}), try the test values.
  4. Export style file and send it to the graphics op, who imports it in JM Graphics. To keep working later, open that file here again.

Fonts: use the font's PostScript name (e.g. Industry-Ultra). The preview uses fonts installed on this computer.

Pick a text item on the right, then click here to place it. Its dot is where the text anchors (left/center/right edge, on the baseline).
