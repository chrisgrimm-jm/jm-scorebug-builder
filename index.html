Scorebug setup

Build a scorebug from a PSD or PNG pieces

PSD: name the layers like the app's PSD import ({awayScore} on a text layer = live text, {awayTeam} on a group = its layers are the options, [outs>=2] = shown when). Rasterize layer styles (strokes, shadows) first: Layer › Rasterize › Layer Style. Open the .psd together with its font files (select them all), or zip them up. Text comes out with Photoshop's exact font, size, color and alignment.

PNG pieces:

  1. Export every piece as a full-frame PNG (1920×1080, transparent, in position), plus one full bug for reference PNG. Put team/player options in folders (e.g. Left teams). Add the bug's font files (.otf/.ttf). Zip it.
  2. Pick the sport and name the style above, then Open PNG zip. Auto build sets up what it can from the reference.
  3. Check each piece, rename the {text1}… fields (e.g. {awayScore}), try the test values.
  4. Export style file and send it to the graphics op, who imports it in JM Graphics. To keep working later, open that file here again.

Fonts in the zip give the exact font and text sizes, and travel inside the style file to the show machine. Without them, text uses a stand-in font and sizes are estimated.

Pick a text item on the right, then click here to place it. Its dot is where the text anchors (left/center/right edge, on the baseline).
